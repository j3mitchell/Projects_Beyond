We have chosen to use functions that map natural numbers to non- negative real numbers because these functions make our deﬁnitions clean. Furthermore, they ﬁt what we would expect a function describing the running time of an algorithm to look like — the size of the problem is a natural number, and the running time is a non-negative real number. However, we sometimes want to express a running time as being in a set n 0 such as O(2 /n). Strictly speaking, this doesn’t make sense because 2 /0is undeﬁned. However, because asymptotic notation focuses on the behavior of the function for suﬃciently large n, this single undeﬁned function value doesn’t aﬀect anything. To accommodate such exceptions to our deﬁnition, we will assume that such functions are “patched” so that undeﬁned or 0 negative values are replaced by 0 (e.g., we assume that 2 /0=0).Wemust be careful, however, that the functions have only a ﬁnite number of negative or undeﬁned values.
