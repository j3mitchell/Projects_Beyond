The ﬁrst and third for loops clearly run in Θ(n) time. Furthermore, the analysis of the fourth for loop is similar to that of the second. Therefore, the entire algorithm runs in Θ(n2)time. Note that the second and fourth for loops in TopSort each contain a nested while loop. Each iteration of this while loop processes one of the edges. Furthermore, each edge is processed at most once by each while loop. The total number of iterations of each of the while loops is therefore the number of edges in the graph. While this number can be as large as n(n−1)∈Θ(n2), it can also be much smaller.
