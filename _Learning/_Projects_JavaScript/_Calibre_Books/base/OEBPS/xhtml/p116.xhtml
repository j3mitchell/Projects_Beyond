However, constant factors can be relevant. For example, two linear-time algorithms will not yield comparable performance if the hidden constants are very diﬀerent. Finally, the running time analyses we have seen in this chapter have all been worst-case analyses. For some algorithms, the worst case is much worse than typical cases, so that in practice, the algorithm performs much better than a worst-case analysis would suggest.
