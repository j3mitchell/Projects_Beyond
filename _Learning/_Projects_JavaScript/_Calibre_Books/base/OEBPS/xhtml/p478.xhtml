(For example, consider the search when trying to add 5 to the matching {{0,8},{2,9},{4,10}} in Figure 14.11.) Constructing this matching therefore uses Ω(k2)time. Wecan now generalize the above construction to arbitrary n by adding or removing a few vertices adjacent to 2k−1. Furthermore, we can add edges {2i,2k + j} for 0 ≤ i<kand 0 ≤ j<i−1 without increasing the size of the maximum-sized matching. However, these additional edges must all be traversed when we try to add vertex 2i+1 to the matching. This construction therefore forces the algorithm to use Ω(na) time.
