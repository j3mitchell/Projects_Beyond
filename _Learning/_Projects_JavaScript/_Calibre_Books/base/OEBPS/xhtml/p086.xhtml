Analyzing Algorithms 67 Deﬁnition 3.20. Let ◦ be a binary operation on functions of the form f : N → R≥0 (for example, ◦ might represent addition or multiplication). Let f be such a function, and let A and B be sets of such functions. We then deﬁne: • f ◦A ={f ◦g | g ∈ A}; • A◦f ={g◦f |g ∈A};and • A◦B={g◦h|g∈A,h∈B}. Example 3.21. n2 +Θ(n3) is the set of all functions that can be written n2 +g(n)forsomeg(n) ∈ Θ(n3). This set includes such functions as • n2 +3n3; • (n3+1)/2, which can be written n2+(n3+1−n2) (note that n3+1−n2 ≥ 0 2 2 for all natural numbers n); and • n3 +2n, which can be written n2 +(n3 +2n−n2). Because all functions in this set belong to Θ(n3), n2 +Θ(n3) ⊆ Θ(n3). Example 3.22. O(n2)+O(n3) is the set of functions that can be written f(n)+g(n), where f(n) ∈ O(n2)andg(n) ∈ O(n3). Functions in this set include: • 2n2 +3n3; • 2n,whichcanbewrittenasn+n;and • 2n3,whichcanbewrittenas0+2n3. Because all functions in this set belong to O(n3), O(n2)+O(n3) ⊆ O(n3). Deﬁnition 3.23.
