Again, such an expression can be constructed in O(1) time. We can extend this abbreviation in a couple of ways. First, we can use one of the constants true or false in place of one of the variables. This will be useful, for example, if we want to specify that some variable has the same value as some speciﬁc bit of the input x,sayx[k]. Because x[k]isnota variable in the formula, it cannot appear in the formula; however, when we’re designing the construction, we don’t know this value. It would therefore be convenient to be able to write Eq(y,x[k]), and to let the construction ﬁll in the appropriate value for x[k]. We then deﬁne Eq(y,true)=y and Eq(y,false)=¬y.
