While these results are disappointing, we at least have some techniques for improving the stack usage. Note that in both MaxSumTD and MaxSuffixTD, the recursive calls don’t depend on any of the rest of the computation; hence, we should be able to implement both algorithms in a bottom-up fashion in order to remove the recursion.
