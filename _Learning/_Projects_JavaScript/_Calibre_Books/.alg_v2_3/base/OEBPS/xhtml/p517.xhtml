For numerical applications, applying the FFT over C,+,· is appropriate; however, for number-theoretic applications like arbitrary-precision integer multiplication, other algebraic structures are more appropriate. The algorithm extends to any commutative ring containing a principal nth root of unity, and over which n has a multiplicative inverse, where n is a power of 2 giving the number of elements in the vectors. Somerings that are particularly useful for number-theoretic applications k are rings of the form Zm,+,·,wherem is of the form 2 +1. The properties of these rings contribute in several ways to the eﬃciency of the Sch¨onhage– Strassen integer multiplication algorithm. First, we can compute n mod k (2 +1) eﬃciently. Second, the principal nth roots of unity in these rings are powers of 2, so that we can use bit shifting to multiply by these roots. Third, when n is a power of 2, it has a multiplicative inverse that is also a power of 2. Fourth, we can compute a product in this ring with a negative wrapped convolution of vectors with half as many elements as would be needed to compute a non-wrapped convolution.
