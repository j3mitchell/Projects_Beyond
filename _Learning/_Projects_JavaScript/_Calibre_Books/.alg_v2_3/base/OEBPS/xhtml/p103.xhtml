Unfortunately, the situation is worse than this —it can be shown that it is impossible to extend the notation to multiple variables in a way that retains the properties of asymptotic notation on a single variable. What we can do, however, is to extend it so that these properties are retained whenever the function inside the asymptotic notation is strictly non-decreasing. Note that restricting the functions in this way does not avoid the problems discussed above, as the functions inside the asymptotic notation in this discussion are all strictly non-decreasing.
