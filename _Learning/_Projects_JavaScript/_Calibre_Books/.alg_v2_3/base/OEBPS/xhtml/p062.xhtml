Note that in Figure 2.7, the last line of SelectByMedian contains a recursive call in which the ﬁrst parameter is A[1 + r + w..n]. However, the speciﬁcation given in Figure 1.1 (page 5) states that the ﬁrst parameter must be of the form A[1..n]. To accommodate such a mismatch, we adopt a convention that allows for automatic re-indexing of arrays when the speciﬁcation requires a parameter to be an array whose beginning index is a ﬁxed value. Speciﬁcally, we think of the sub-array A[1+r+w..n]asan array B[1..n−(r+w)]. B is then renamed to A when it is used as the actual parameter in the recursive call.
