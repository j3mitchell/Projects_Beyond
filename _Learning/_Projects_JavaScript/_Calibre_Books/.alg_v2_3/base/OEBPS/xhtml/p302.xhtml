It is easily seen that the space required by the ImmutableDictionary is in Θ(n) in the worst case. However, the hidden constants can be rather large. Speciﬁcally, the primary hash table can contain nearly 3n locations, and the secondary hash tables can contain a total of nearly 18n locations. As a result, nearly 21n array locations can be used to store n data items.
