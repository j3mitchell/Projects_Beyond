To implement a MatchingGraph, we need two representation vari- ables: • a Graph bipartite representing the bipartite graph; and • a readable array matching[0..n − 1] representing the matching, so that matching[i] gives the vertex to which i is matched, or −1ifi is unmatched. Its structural invariant will be that for 0 ≤ i<n,ifmatching[i] = −1, then matching[matching[i]] = i. We also include a constructor that constructs a MatchingGraph from a given bipartite graph with an empty matching.
