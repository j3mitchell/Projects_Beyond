248 Algorithms: A Top-Down Approach Figure 7.2 Implementation of VArray 7.2 Hashing The technique we will develop over the remainder of this chapter is known as hashing. The basic idea behind hashing is to convert each key k to an index h(k)usingahash function h, so that for all k,0≤ h(k) <mfor some positive integer m. h(k) is then used as an index into a hash table,whichis an array T[0..m −1]. We then store the data item at that index.
