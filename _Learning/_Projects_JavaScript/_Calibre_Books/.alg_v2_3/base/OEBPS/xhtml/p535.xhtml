We say that a CNF formula is in k-conjunctive normal form (or k-CNF) if no clause contains more than k literals. We then deﬁne k-Sat to be the problem of determining satisﬁability for a given k-CNF formula. Though we won’t show it here, it turns out that 2-Sat ∈P. In what follows, we will show that 3-Sat is NP-complete.
