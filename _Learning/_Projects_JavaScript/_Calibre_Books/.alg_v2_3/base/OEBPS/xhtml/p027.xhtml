We can again use the the top-down approach to reduce an instance of Insert to a smaller instance of the same problem. According to the precondition (see Figure 1.3), A[1..n−1] must be sorted in nondecreasing order; hence, if either n =1orA[n] ≥ A[n−1], the postcondition is already satisﬁed. Otherwise, A[n − 1] must be the largest element in A[1..n]. Therefore, if we swap A[n]withA[n − 1], A[1..n − 2] is sorted in nondecreasing order and A[n] is the largest element in A[1..n]. If we then solve the smaller instance A[1..n−1], we will satisfy the postcondition. The algorithm is shown in Figure 1.4.
