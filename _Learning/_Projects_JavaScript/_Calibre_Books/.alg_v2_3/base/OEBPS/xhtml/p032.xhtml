For example, a speciﬁcation of a data structure must certainly include preconditions and postconditions for the operations on the structure. In addition, the speciﬁcation must in some way describe the information represented by the structure, and how operations on the structure aﬀect that information. As a result, proofs of correctness must take into account this additional detail. While the analysis techniques of Chapter 3 apply directly to operations on data structures, it will be necessary to introduce a new technique that analyzes sequences of operations on a data structure. Furthermore, even the language we are using to express algorithms will need to be enriched in order to allow design and analysis of data structures.
