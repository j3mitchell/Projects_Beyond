The rest of the implementation is the same as for ShortDisjointSets; however, because path compression can decrease the height of a node i without updating height[i], this value is no longer guaranteed to give the height of node i. For this reason, we will change the name of this array to rank and weaken the structural invariant so that rank[i] is at least the height of i. The precise meaning of rank[i] is now rather elusive, other than the fact that it gives an upper bound on the height of i. Clearly, the running time of CompressedDisjointSets.Find is in O(h), where h is the height of the tree.
