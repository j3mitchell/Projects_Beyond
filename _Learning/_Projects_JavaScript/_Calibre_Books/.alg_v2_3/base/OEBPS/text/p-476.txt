                In order to complete the matching algorithm, we need to be able to
            ﬁnd a path from i to j in a directed graph. Because the maximum ﬂow on
            the constructed ﬂow network is no more than n/2, where n is the number
            of vertices in the bipartite graph, the Ford–Fulkerson algorithm will not
            perform badly. Therefore, we will use depth-ﬁrst search to ﬁnd paths. (We
            leave it as an exercise to implement the algorithm using breadth-ﬁrst search.)
            We therefore need a Searcher with the following representation variable:
            • incoming[0..n − 1]: a readable array of Edges giving the incoming edge
              in the depth-ﬁrst spanning tree for each vertex reached.
            The implementation of PathSearcher is shown in Figure 14.9.
