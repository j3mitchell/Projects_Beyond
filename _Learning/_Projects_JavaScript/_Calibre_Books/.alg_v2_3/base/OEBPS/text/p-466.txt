             Figure 14.3   The Ford–Fulkerson algorithm for network ﬂow
               Precondition: G is directed Graph in which each edge contains a Nat
               giving its capacity, and source and sink are distinct Natslessthanthe
               number of vertices in G.
               Postcondition: Returns a directed graph F in which the contents of the
               edges give a maximum ﬂow for G from source to sink.
               NetworkFlow(G,source,sink)
                  F ←CopyGraph(G,true); R←CopyGraph(G,false)
                  P ←FindPath(R,source,sink)
                  // Invariant: F combined with a maximum ﬂow for R gives a maximum
                  // ﬂow for G. P is a ConsList containing the Edges of a path from
                  // source to sink in R if there is such a path; otherwise, P = nil.
                  while P = nil
                     m←MinVal(P);AddFlow(F,P,R,m)
                     P ←FindPath(R,source,sink)
                  return F
